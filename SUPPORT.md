# Support

GbEmu is a study project. Support is best-effort and focused on the emulator
code, docs, and local development workflow.

## Good Issues

- Reproducible emulator bugs with the ROM name, cartridge type, and expected
  hardware behavior
- Phoenix/LiveView runtime problems with logs and environment details
- Documentation gaps
- Open-source readiness or security concerns

## Out of Scope

- Requests for commercial game ROMs or BIOS files
- Help downloading copyrighted games
- Public hosting operations for unrestricted internet traffic
- Legal advice

For ROM and BIOS guidance, read [docs/roms.md](docs/roms.md).

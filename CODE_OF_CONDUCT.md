# Code of Conduct

GbEmu should be a welcoming place for people learning emulator internals,
Elixir, Phoenix, and hardware documentation.

Be respectful, patient, and specific. Assume good intent, but accept feedback
when something lands poorly. Harassment, threats, personal attacks, spam, and
requests for copyrighted ROMs or BIOS files are not welcome.

Maintainers may edit, hide, or remove issues, comments, or pull requests that
violate these expectations.
